# 手动检查更新：主窗口内反馈

从 macOS 菜单点击「检查更新…」后，在现有主窗口右上角显示非阻塞状态，不创建新窗口。

- 手动检查开始时立即显示转圈和「正在检查更新…」。重复点击同一次检查不重复发请求；如果后台检查正在进行，复用结果并显示手动检查状态。
- 找到更新时移除加载状态，沿用现有原生更新选择弹窗。没有更新时，原位置显示「已是最新版本」，随后自动收起。检查失败时停止转圈，显示失败提示和「重试」按钮。
- 启动时的后台检查仍保持静默，除非用户主动点击检查。下载进度、签名校验和安装行为保持不变。
- Electron 主进程管理检查状态，经 preload 向主窗口发送有限的状态消息；重试入口不接受 URL 或更新参数。主窗口用可读状态提示反馈，启用减少动态效果时可不播放转圈动画。
- 用可控制的模拟请求覆盖检查中、重复点击、无更新、失败和重试；在 Electron 中验证有更新时仍打开原弹窗，且没有额外窗口。

发版影响：需要修改桌面端更新逻辑和 preload，不能走仅替换 renderer 的热更新轨道。
