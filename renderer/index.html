机票下单流程

搜索 → 选航班号 → 选报价 → 验价 → 创单 → 支付。乘机人可从常旅客接口拉取。

1

航班搜索

POST /flight/search
因私机票仅支持单航段、单乘机人，乘机人须与登录人本人实名一致；下单时行程类型会自动按单程提交。
2

选择航班报价

POST /flight/searchProduct · /flight/searchDetail
先在上一步选择航班号
3

乘机人 / 验价

POST /air/order/price
POST /passenger/list，点选后自动填入乘机人
4

创建订单

POST /air/order/create
5

支付 / 查单

POST /air/order/pay · /pay/alipay

机票售后

可直接使用已有订单。预估费用不等于提交，提交及支付前请核对环境、订单和票号。

酒店下单流程

搜索 → 详情选房型 → 验价 → 创单 → 支付。字段来自 H5 的 hotel 接口契约。

1

酒店搜索

POST /hotel/search
因私酒店仅支持本人预订一间房（1 间 1 人），入住/离店日期须在今天至未来 30 天内，入住人须与登录人本人实名一致。
2

酒店详情 / 选房型

POST /hotel/detail
3

入住人 / 验价

POST /hotel/orders/price
从常用出行人选择入住人，自动填入姓名、证件与手机号
4

创建酒店订单

POST /hotel/orders/create
5

支付 / 查单

POST /hotel/orders/{orderNo}/pay

退订 / 取消

取消结果可能异步，提交后可查退款单或订单详情

登录

登录接口走 Go 网关（默认前缀 /goco）。登录成功后 token 会作为 Authorization: Bearer 注入所有业务请求。

接口配置

Java 业务和 Go 登录共用所选环境域名。Java travel 接口拼接 /api/tmc，Go co 登录接口拼接 /goco。保存切换后需重新登录。

配置保存在本机 localStorage
